# Rubrics

One file per stage. Questions are ordered from "would mislead the next stage" to "precision". Each question says what input to check the output against. Add questions when a user gate catches something the critic missed; note the date and the case.

| Stage | File | Central claim to rebut |
|---|---|---|
| scouting shortlist | [screened.md](screened.md) | "these sources serve problem R*n*" |
| digest | [digest.md](digest.md) | "this is what the source claims and how it measured it" |
| aligned | [aligned.md](aligned.md) | "the paper's mechanism transfers to company problem R*n* through structure S" |
| proposed | [proposed.md](proposed.md) | "X improves M by ≥ Y over Z on B under C, and nobody has done it" |
| reproduced | [reproduced.md](reproduced.md) | "our harness reproduces the paper within tolerance" |
| extended | [extended.md](extended.md) | "the extension runs were fair to the baseline" |
| plotted | [plotted.md](plotted.md) | "the figures support the summary's claims" |
| deck | [deck.md](deck.md) | "every slide claim traces to evidence" |
